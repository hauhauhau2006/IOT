### RULE:

**Thiết lập: Tạo một Repository chung trên GitHub. Ba thành viên sẽ clone repo này về máy.**

**Chia nhánh (Branching): Không ai được code trực tiếp lên nhánh main. Mỗi người khi làm task của mình sẽ tạo một nhánh riêng (ví dụ: nhanh-cua-hau, nhanh-tien-xu-ly). Làm xong sẽ tạo Pull Request (PR) để gộp code vào main.**

**File .gitignore (Cực kỳ quan trọng): Tuyệt đối không đẩy các file dữ liệu (.pcap, .csv), file mô hình (.pkl) hoặc thư mục môi trường ảo (venv) lên GitHub vì chúng quá nặng. Hãy thêm các đuôi file này vào .gitignore.**
